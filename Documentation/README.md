# Maya - Delivery Drone Simulator: publishing kit

Prepared 10 October 2026 (Asia/Kolkata). These are public-facing preparation documents for the current Windows v0.1 build, not evidence of a Steam submission or approval.

1. [Steam submission checklist](STEAM-SUBMISSION-CHECKLIST.md) — account, metadata, launch settings, build review and outstanding work.
2. [Store copy](STORE-COPY.md) and [Steam BBCode](STORE-ABOUT.bbcode.txt) — truthful descriptions of the current game.
3. [Artwork requirements](ARTWORK-REQUIREMENTS.md) and [trailer plan](TRAILER-SHOT-PLAN.md) — upload dimensions and capture requirements.
4. [Content survey and AI disclosure draft](CONTENT-SURVEY-AI-DRAFT.md) — draft answers that require publisher verification.
5. [Source build guide](SOURCE-BUILD-GUIDE.md) and [rights/dependencies](RIGHTS-AND-DEPENDENCIES.md) — what a public source checkout does and does not contain.

The player controls a six-wheel **ground delivery robot**. “Drone” is the requested game title; the current game does not provide aerial flight. Four delivery offers are playable. Planned missions are not advertised as available content.

All Steam specifications were checked against linked official documentation on the preparation date. Steamworks account fields and requirements can change; confirm the live dashboard before submission.
